# Memory Profiles Fixture Playbook

Operating guide. Sections are addressable, so a session receives the procedure
it needs rather than the whole file.

## Review

Check the archive invariants against the diff. Record findings as candidate
memories; do not promote them in the review session.

## Incident Runbook

Load the operational archive first. Record observations against the incident
reference. Diagnosis does not become archive truth without operator review.

## Invariants

Critical invariants block the session. High invariants are reported and
proceed.

## Onboarding

Read the archive, then this playbook, then the lessons file. Ask before
changing any governed surface.
