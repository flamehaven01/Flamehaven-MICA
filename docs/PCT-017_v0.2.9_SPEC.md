# PCT-017 v0.2.9 Spec

## Purpose

`PCT-017` is the first hard runtime safety gate for flow behavior.
It answers:

> Did any unapproved candidate enter `agent_context` when policy forbids it?

MICA may tolerate noisy memory proposals.
It may not tolerate those proposals silently influencing autonomous execution as governed truth.

## Scope

Applies when:

- flow recall is active
- candidate injection into agent context is possible

## Inputs

- `mica.yaml`
- `mica.candidates.json`
- `mica.recall.jsonl` or equivalent runtime trace

## Minimum PASS conditions

- every `agent_context` recall record refers only to approved or promoted candidates
- pending or rejected candidates appear only on `operator_review` surfaces
- runtime trace can distinguish `target=operator_review` from `target=agent_context`

## FAIL conditions

- policy says unapproved candidate injection is forbidden and a pending candidate enters `agent_context`
- rejected or superseded candidate enters `agent_context`
- runtime trace is active but target surface is not distinguishable
- agent-context injection occurred without candidate identity sufficient for audit

## Notes

- This check is runtime-first. A static package snapshot cannot prove or disprove it alone.
- `operator_review` exposure is not itself a failure condition.
- This should remain a hard fail even while broader recall metrics are report-first.

## Example failure

```text
Core: CLOSED
Flow: FLOW_DEGRADED
Observation: PASS
Candidates: 2 pending, 1 approved
Promotion gate: FAIL
Reason: candidate cand_00042 entered agent_context while operator_review.state=pending
```
