# MICA Docs Index

This folder contains **analysis, comparison, release-planning, and forward-looking design notes**.

These files are not the normative core contract. They help humans and AIs understand:

- why MICA exists
- how stable and draft branches differ
- how MICA compares with adjacent memory patterns
- what the next release is trying to prove
